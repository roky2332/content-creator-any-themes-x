# AI / Tech: формат «история от первого лица» (только для ниши AI / Tech)

> Добавлено 2026-11-07 по просьбе автора. Референсы: `examples/ai-tech/first-person-reference-posts.txt`.
> Этот формат применяется ТОЛЬКО к нише AI / Tech. Для остальных ниш действуют `story-method.md` и `post-format.md`.

## Условие использования
Истории в этом формате вымышленные, рассказчик — автор от первого лица.
По договорённости с автором такие тексты пишутся для розыгрыша друзей (личные чаты, показ с экрана) и не публикуются в X как реальный случай.
Для публичного поста в X тот же формат используется только с пометкой-реконструкцией в конце или на реальном задокументированном случае.

## Структура
1. **Хук:** эмоция + «Claude Code just found…» + точная цифра (деньги / количество) + многоточие «…»
   - «I feel sick.», «Holy sh*t.», «I still don't know how to tell my wife…»
2. **Вторая строка поднимает ставки:** работа, жена/семья, интимное, ревность, дети
3. **Бытовой вход:** откуда пришла угроза — подарок в посылке, дешёвый гаджет, бесплатное приложение «после Storage Full». Узнаваемо для любого читателя
4. **Ошибка героя:** одна привычная кнопка («Trust This Computer?», «Allow»), честное признание: «I'll be honest, that was my mistake»
5. **Обнаружение:** «Last night I set up Claude Code to…» → тревога → привязка к видео («The video is the end of that check», «yellow warnings, then red ones»). Видео — анимация-проверка (см. `animations/`)
6. **Простое объяснение механики** одной-двумя фразами («A USB cable has wires for power and wires for data…»)
7. **Список улик стрелками →** с точными числами и частично скрытыми данными (`47.***.***.12`, `+1 (312) *** **19`, `IMEI 35 ********** 82`)
8. **Время как удар:** «last night at 2:14, while we slept», «6 minutes before I found it»
9. **Действия героя стрелками →:** что сделал, частичная победа
10. **Опора на авторитет** (по желанию, только реальные факты)
11. **Незакрытый эмоциональный финал:** что спасти не удалось, кому ещё предстоит сказать
12. **CTA:** «… is in the first comment», «Save this and check … tonight»

## Оформление
- Первое лицо, разговорный тон, короткие абзацы
- Точки в конце предложений допустимы (как в референсах), длинные тире не используем
- Списки стрелками → разрешены и желательны
- Финальный вопрос не обязателен, вместо него CTA
- Длина 200–350 слов
- Каждая новая история — новый сюжет и новая угроза, не повторять референсы
- Все номера, IP, IMEI — частично скрыты звёздочками; IP из диапазонов документации, телефоны 555-01xx или скрытые

## Доработка сюжетов автора (разрешено автором, 2026-11-07)
Когда автор присылает сюжет, можно и нужно его усиливать. Рычаги:
1. **Начинать с последствия, а не с находки** («My girlfriend got a photo from me last night. I never sent it…»)
2. **Поворот репутации:** угроза действует от имени героя — все думают, что это сделал он
3. **Таймер** (по уместности): срок, к которому всё станет ещё хуже
4. **Одна конкретная деталь вместо больших чисел** — читатель додумывает сам, без откровенностей
5. **Открытая загадка** в конце (что-то, что не объясняется) — двигает комментарии
6. **Меньше технических действий, больше человеческих реакций** (кто что написал, кто не ответил)

Предпочтения автора по сюжетам:
- Без свадеб; отношения — просто «девушка»
- Всё происходит на телефоне (без ноутбука): анимацию автор показывает на экране телефона
