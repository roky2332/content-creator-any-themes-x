# Анимации-реквизит для экрана телефона

## Что есть
- `phone-terminal.html` — живая страница (режимы `#copy`, `#scan`), открывается на телефоне по ссылке artifact
- `videos/scenes.js` + `videos/render.js` — 8 сцен, рендер в MP4 1080×1920, 30 fps: `cd videos && node render.js [сцена ...]`

## Что понравилось автору (2026-11-07)
✅ **01 Photos** — лог копирования + ряды размытых превью фото
✅ **02 Scan** — плотный лог, разгоняется, цвет фиолетовый → жёлтый → красный
✅ **03 Map** — тёмная карта, метки мест с временем, маршрут, облако точек, лог координат
✅ **06 Hex** — янтарный CRT hex-дамп с подсветкой найденных строк

✅/🆕 **09 BTSpy** (2026-11-09) — к посту про фейковые AirPods: шапка «AirSync Pro · background» со счётчиком 11,382 записей и аплоадами на 203.0.113.**, мини-карта с моим маршрутом и устройствами рядом (Emma's iPhone, iPhone (4)), быстрый лог BLE-записей с координатами, июль → ноябрь, строки apple_id plaintext

Не зашли: 04 Messages, 05 Contacts, 07 Transfer, 08 Analysis.

**Вывод для новых анимаций:** автору нравится «сырой» терминальный / хакерский вид — тёмный фон, плотный быстро бегущий моноширинный текст, ощущение вскрытия данных, нарастание (скорость, цвет). Меньше — «чистые» UI-дашборды и интерфейсы приложений.

## Правила
- Все данные генерируются: телефоны 555-01xx, IP из RFC 5737 (203.0.113.x, 198.51.100.x, 192.0.2.x), имена выдуманные
- Длина видео 25–35 с
