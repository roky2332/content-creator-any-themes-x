# Проект автора: 3D-редактор квартиры «My Room»

> Сохранено как проект автора 2026-11-17. Цель: дополнять сцену и спроектировать всю квартиру автора.
> Последняя утверждённая версия видео: `animations/videos/final/22-room-editor-28s-60fps-track.mp4`
> (28 с, 1920×1080, 60 FPS, трек автора с 0:18; финальная плашка «Layout applied» убрана по просьбе автора).

## Файлы
| Файл | Что внутри |
|---|---|
| `room.js` | 3D-сцена (three.js): стены, свет, мебель, материалы, жалюзи. `ROOM.build`, `ROOM.render(state)`, `ROOM.proj` |
| `ui.js` | Интерфейс поверх сцены (полупрозрачные стеклянные панели) |
| `timeline.js` | Камеры, расстановки, наброски `STILLS`, сценарий анимации `TL(t)`, длина `DUR` |
| `render.js` | Рендер через Playwright + ffmpeg |
| `t-*.jpg` | Текстуры: пол (дуб), стены, светлый дуб, лён (CC0, Poly Haven, нейтрализованы) |

Установка один раз: `npm i` (ставит three@0.160.0).
- Наброски: `node render.js --stills` → `out/still_N.jpg`
- Отдельные кадры: `node render.js --t=2.5,10,20` → `out/t_<сек>.jpg`
- Видео: `node render.js` → `out/room.mp4` (60 FPS)
- Трек: `ffmpeg -i out/room.mp4 -ss <старт> -i трек.m4a -map 0:v:0 -map 1:a:0 -t <DUR> -c:v copy -af "afade=t=in:st=0:d=0.05,afade=t=out:st=<DUR-1.5>:d=1.5" -c:a aac -b:a 192k out.mp4`

## Комната 1: спальня 4 × 6 × 3 м
Оси: x — ширина 4 м (0 = левая стена), z — длина 6 м (0 = стена с окном), y — высота.
- **Стена с окном (4 м, z=0):** окно 1.2 × 1.4 м (x 1.3–2.5), под ним чёрная трубчатая батарея; в правом углу тёмно-серый стол с ноутбуком и стулом, над ним 2 графитовые полки
- **Левая стена (6 м, x=0):** шкаф из светлого дуба в углу (дверцы смотрят на правую стену), комод с лампой, кровать в углу у стены с дверью (изголовье к двери, смотрит на окно), кровать ~1.8 × 2.15 м
- **Правая стена (6 м):** вешалка на колёсах с футболками, худи и лёгкими куртками
- **Стена с дверью (4 м, z=6):** дверь x 2.6–3.5
- **Ковёр:** большой, от двери почти до стула
- **Цвета (по референсу автора):** светло-серые стены, пол светлый дуб, светлое дерево + графит + чёрный металл, серый текстиль

## Интерфейс (стиль автора)
- Тёмный, блоки полупрозрачные стеклянные
- Слева при клике на мебель выезжает панель объекта: размеры, ползунок (поворот / насыщенность / покрытие), переключатели, образцы отделки, 4 кнопки действий
- Справа панель комнаты: выбор комнаты, счётчик изменений, вкладки Layout / Materials / Light / Other, карточки зон Sleep / Work / Storage / Free floor
- Снизу: Room / Structure / Furniture + Top view / Floor plan / Walk-through / Undo
- Подписи-«пилюли» над мебелью, курсор с кругом клика

## Правила анимации (от автора)
- Камера сверху под углом, без облётов. Движется только к объекту, по которому кликнули, и обратно
- 60 FPS, 1920×1080
- Перед рендером автору сначала наброски кадров

## Сценарий текущей версии (28 с)
| Время | Действие |
|---|---|
| 0–5 с | Клик по комоду → Move, сдвигается к кровати |
| 6.75–13 с | Клик по вешалке → Move к шкафу → ползунок Rotation разворачивает её |
| 14–15.4 с | Клик по стене → образец, стены темнее (тёплый серо-бежевый) |
| 16.6–20 с | Клик по ковру → терракотовый образец → ползунок Saturation |
| 21–24.4 с | Клик по окну → Add blinds → ползунок покрытия, жалюзи на 50% |
| 25.3–28 с | Клик по Floor plan → вид сверху |
